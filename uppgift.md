# Todo-app i React med TypeScript

## 📝 Projektbeskrivning

Du ska bygga en todo-app i React med TypeScript.

---

## ✅ FÖR GODKÄNT

### Funktionella krav

Användare ska kunna:

- [x] ➕ Lägga till en todo
- [x] 📋 Se alla todos i en lista
- [x] ✔️ Markera todos som klara
- [x] 🗑️ Ta bort en todo

### Tekniska krav

- [x] **Framework**: Applikationen ska vara byggd med React och typescript
- [x] **Komponenter**: Ha minst 3 React komponenter
- [x] **Datalagring**: Använd localStorage för att spara todos
- [ ] **Testning**: Ha minst 3 enhetstester/unit tester skrivna med Testing Library
- [ ] **CI/CD**: Ha med Continuous Integration/Continuous Delivery
- [ ] **CI**: Ska vara uppsatt i GitHub Actions som automatiskt kör tester vid push till main/master branchen
- [ ] **CD**: Ska vara uppsatt mot Netlify eller Vercel så det publicerar en ny version vid push av ny kod till main/master branchen
- [ ] **Publicering**: Projektet ska vara publicerat på Netlify eller Vercel vid inlämning
